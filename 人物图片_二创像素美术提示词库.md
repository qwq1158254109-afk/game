# Unity 学生成长模拟卡牌游戏：人物图片提示词库（二创像素版）

> 建议文件名：`CHARACTER_PIXEL_PROMPT_LIBRARY_FANWORK.md`  
> 文档用途：交给 Codex、AI 生图工具、美术参考流程或 Unity 原型资源生成流程使用。  
> 适用范围：本文件只设计**人物头像、半身像、事件角色图、Boss 人格化图、状态拟人图、角色占位图提示词**。  
> 前提定位：本项目为**非商业二创 / 学习向 / 原型向项目**。人物美术按照《不要喂食猴子》的低饱和复古像素、监控窗口、旧电脑桌面、多窗口观察、生活切片、荒诞现实主义氛围进行设计。

---

## 0. 项目基础说明

本项目是一款基于 Unity 的学生成长模拟经营 + 卡牌回合制挑战游戏。

核心玩法结构：

```text
阶段开始
↓
阶段有固定时间限制
↓
玩家选择活动：小游戏 / 卡牌挑战 / 事件 / 休息 / 商店 / 训练
↓
获得属性、卡牌、道具、状态变化
↓
阶段末出现 Boss
↓
使用当前属性、卡组和道具击败 Boss
↓
进入下一阶段
↓
最终根据成长结果进入不同结局
```

人物图片主要服务于：

| 系统 | 用途 |
|---|---|
| 事件系统 | 事件头像、对话角色、选择事件插图 |
| 活动系统 | 活动入口角色、小游戏说明角色、商店角色 |
| 关系系统 | 同学、老师、家长、社团、补习班等关系展示 |
| Boss 系统 | 阶段 Boss、压力 Boss、家庭期待 Boss 的拟人化形象 |
| 状态系统 | 拖延、分心、自律、疲劳等状态拟人 |
| UI 装饰 | 学生档案、成长报告、观察窗口、弹窗头像 |

## 1. 二创像素美术定位

### 1.1 主要参考氛围

人物整体按照《不要喂食猴子》式的观察感来设计：

```text
像素化人物
低饱和色彩
旧电脑观察窗口
监控视角
房间切片感
人物生活隐私感
轻微荒诞现实主义
日常但略带压迫的空间氛围
```

但本项目主题是学生成长，所以人物应转化为：

```text
中国校园生活人物
家庭教育环境人物
老师 / 同学 / 家长 / 社会角色
学生成长观察系统里的档案头像
阶段 Boss 的压力拟人
状态牌的抽象拟人
```

### 1.2 人物视觉原则

```text
人物不需要精致大立绘，而应像旧电脑窗口中被观察到的生活角色。
人物可以有轻微夸张，但不能变成恐怖怪物。
学生角色应保持低细节、不可识别真实身份、非成人化。
人物脸部可以简化为像素五官或剪影，重点放在姿态、服装、道具和所在空间。
```

### 1.3 二创边界

虽然项目定位为非商业二创，但仍建议：

```text
可以参考：低饱和复古像素、监控窗口、生活切片、荒诞日常、旧电脑界面感
不要直接使用：原作角色、原作头像、原作 UI、原作 Logo、原作字体文件、原作截图
可以做致敬：观察系统、房间窗口、像素剪影、旧电脑档案头像
不要做复刻：完全相同的人物比例、具体脸型、原作窗口结构或原作角色姿态
```

## 2. 人物图片规格

### 2.1 推荐尺寸

| 资源类型 | 基准尺寸 | 导出尺寸 | 用途 |
|---|---:|---:|---|
| 小头像 | 48x48 | 192x192 | 事件列表、关系图标 |
| 标准头像 | 64x64 | 256x256 | 对话头像、UI 弹窗 |
| 半身像 | 96x128 | 384x512 | 事件详情、角色档案 |
| 监控窗口人物 | 160x90 / 320x180 | 640x360 | 活动窗口、场景切片 |
| Boss 人格化图 | 128x128 / 160x160 | 512x512 / 640x640 | Boss 预览、阶段警报 |
| 状态拟人图 | 64x64 / 96x96 | 256x256 / 384x384 | 状态牌、负面效果提示 |

Unity 导入建议：

```text
Texture Type: Sprite (2D and UI)
Filter Mode: Point (no filter)
Compression: None
Generate Mip Maps: Off
Pixels Per Unit: 16 或 32，项目内保持一致
```

### 2.2 人物构图

人物可以采用三种构图：

| 构图 | 说明 | 适用 |
|---|---|---|
| 档案头像 | 正面或 3/4 角度，背景是旧电脑档案框 | 关系系统、事件头像 |
| 监控窗口 | 角色在房间 / 教室 / 家庭空间中被观察 | 活动入口、剧情事件 |
| 抽象拟人 | 人物和象征物组合，不强调真实身份 | Boss、状态牌、压力系统 |

## 9. 验收清单

生成或绘制人物图片时，逐项检查：

```text
[ ] 是否为像素风，而不是高清插画或写实图？
[ ] 是否有旧电脑 / 监控窗口 / CRT 观察感？
[ ] 是否使用低饱和复古色彩？
[ ] 是否服务于校园成长、家庭、社交、Boss 或状态系统？
[ ] 是否没有原作截图、Logo、UI 图标或商业素材？
[ ] 是否没有直接复刻原作角色？
[ ] 学生角色是否非成人化、非性感化、不可识别真实身份？
[ ] 是否没有血腥、恐怖、暴力内容？
[ ] 是否没有复杂文字被画死在图片中？
[ ] 是否适合 Unity 事件头像、角色档案、Boss 预览使用？
```
