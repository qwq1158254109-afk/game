### 3. 送礼界面重构（merge `5d4821b` + `fec6adf`）

用户报「赠送礼物时布局很乱」。根因是几何冲突：完整背包窗口 800×560 居中（占 y 80~640），对话框 1200×340 贴底、选项区从 y 424 往上长 432 高，**必然重叠**。

新增 `Assets/Scripts/StudentGrowth/Dialogue/GiftPickerView.cs`（820×268，底边 y=424 与 optionsRoot 同一条），`DialogueRunner.OpenGiftPickerNextFrame` 改调它，不再开背包。只列可赠送道具（排除 `ItemType.StageOnly`），5×2 + 翻页，点格子选中 → 右侧详情 → 「赠送」才送出。

**实现中踩到四个 UI 坑，全部写进了代码注释：**

1. **`PixelPanel.ResolveReferences()` 会把面板下第一个 Text 认成自己的标题**，`ApplyStyle()` 用 `Subtitle` 样式刷它，`OnEnable` 还会反复刷。表现：标题字号被压成 24，比正文还小。解法：先塞一个隐藏占位 Text 给 `panelStyle.titleText`。
2. **`Button` 默认 `ColorTint` 会把 `targetGraphic.color` 刷回白色**，手动设的格子底色被抹掉，看着像图标飘在空中。解法：`button.transition = Selectable.Transition.None`（`InventoryPanelView:259` 早就这么写了）。
3. **格子用 `quickbarSlotSprite`（panel_paper 米黄纸纹）会和米黄卡片底糊成一片**。解法：`GetSolidSprite()` 纯色深棕底 + 选中暖黄。
4. **文字 rect 高度 < 字号 × 行高时被 `Truncate` 裁得只剩几道横线**（标题看起来像下划线）。解法：rect 高度按字号 ×1.6 起算。另外**像素字体缺「‹ ›」字形**，翻页按钮必须用中文。

**`PixelButton.ApplyStyle()` 会调 `ApplyPixelText(labelText, ..., ButtonText)` 重设字号**，外部 `SetLabelFontSize()` 无效（OnEnable 会刷回 24）。想让按钮文字变小只能改按钮尺寸。

### 4. 阶段地图确认锁移动（merge `50671dd`）

需求：点地点 → 确认进入 → 过场里角色还能走。**之前 4 次尝试都用 `SetActive(false)` / 批量关 `SpriteRenderer` 冻结玩家，全部翻车**（角色消失/外观变化/进场景闪烁/书房卡死）——玩家对象是 `DontDestroyOnLoad`，跨场景存活，关掉之后没有可靠时机恢复。

本轮改用 `GameplayInputGate`（`RpgPlayerController:45,107` 本来就检查它），**零接触玩家对象**：
- `ConfirmSelected` / `Back` 先 `StartCoroutine(GuardUntilSceneChanges())`（协程同步跑到第一个 yield，Acquire 当场生效），再触发路由
- `SceneManager.sceneLoaded` → `ReleaseGate()`
- 协程 1.5 秒超时兜底 + 交互失败立即释放 + `OnDestroy` 再兜一层

**为什么必须带超时**：`TryInteract` 返回 `success=true` 不等于一定会 `LoadScene`（`LocationSceneRouter:51` 显示模式被拦时直接 return；`ReturnToStageMap` 也有多条不切场景分支）。无脑 Acquire 会把角色永久锁死，比「过场能走」严重得多。
