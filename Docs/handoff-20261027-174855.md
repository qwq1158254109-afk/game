### 四条硬教训（今天踩出来的，别重复）

**1. 「点击变绿」的真根因是 Unity 的 Selectable 状态机，不是我们的代码**

`GameUiStyle.ApplyButton` 在主题有状态贴图时会把按钮设成 `Selectable.Transition.SpriteSwap`，
并给 `spriteState.selectedSprite` 赋 `button_selected.png`（**墨绿色**）。
鼠标点击 → 按钮进入 selected → Unity 自动换图，把我们手动设的 `Image.sprite` 整个覆盖，
且选中态会一直留着。

→ 修法：`PixelButton.ApplyStyle()` 里 `GameUiStyle.ApplyButton` 之后强制
`button.transition = Selectable.Transition.None`。
→ **排查口诀：按钮自己变色时，先看 `Selectable.transition` 和 `spriteState`，再看自己的代码。**

**2. 九宫格贴图变形，先调 `pixelsPerUnitMultiplier`，别急着换纯色**

木牌 64×24、border 5px、PPU 16。默认 `multiplier=1` 时边框在 UI 里被放大到约 31px，
372 宽的格子里左右各占 31px、中间只剩一条 → 看起来"两条粗竖条"。
设 3.5 后边框约 9px，形状保留。

**3. 清列表时 `SetParent(null)` + `Destroy` 会留下"幽灵节点"**

`Destroy` 延迟到帧末，而节点脱离父级后 `localPosition` 还是原来那套 → **世界坐标飘了**，
这一帧旧格子以错位形态继续渲染（截图里那些莫名其妙的横条/绿线）。
→ 修法：`SetActive(false)` 之后再 Destroy，立即不可见。

**4. Read 工具看 PNG 会转 JPEG，深色块边缘出现绿色伪影**

我两次追查"绿线"都扑空，最后用 PIL 逐像素采样才排除。
→ **怀疑渲染问题时先做像素采样**（`Docs/Screenshots/` 下的图都可以直接采样）。
