## 3. 两个必须记住的设计决定（别改回去）

### 3.1 不要引用 `LitMotion.Extensions`

它用 `versionDefines` 判定本工程满足「`com.unity.ugui` >= 2.0.0」→ 定义
`LITMOTION_SUPPORT_TMP`，内部引用 `Unity.TextMeshPro` 的 `TMP_Text`。
一引用它，`StudentGrowth.Runtime` 就必须连带引用 `Unity.TextMeshPro`，
否则 `CS0012`。本工程用 uGUI 的 `Text`、没有用 TMP。

正确做法是在核心库上 `Bind`（等价于 Extensions 的实现）：

```csharp
.Bind(canvasGroup, static (x, target) => target.alpha = x)
.Bind(fadeImage, static (x, target) => { var c = target.color; c.a = x; target.color = c; })
.Bind(rect,      static (x, target) => target.anchoredPosition = x)
```

### 3.2 动效必须用 `MotionScheduler.UpdateIgnoreTimeScale`

本工程暂停菜单与设置界面会把 `Time.timeScale` 置 0
（`GameApplicationRuntime.cs:147`、`SettingsMenuController.cs:203`）。
默认调度器走 scaled time，提示栏与黑场遮罩会在暂停时卡在半透明、永远播不完。

另外 `MapInteractionPromptView` 里那层「消息 + 可见性都没变就直接 return」的守卫
**不能删**：`MapInteractionFlowController.RefreshTarget` 是每帧调用的
（`MapInteractionFlowController.cs:146-149`），删掉守卫动效会每帧重启。
