## 追加：面板收到 1200 宽 + 物品栏只留悬停（同日第二轮，merge `0b7be45`）

用户反馈两条：「太大了这个屏幕装不下」「物品栏只要悬停变化，不要点击变化」。

**尺寸**：画布参考分辨率是 1280x720（`MapUiFactory.EnsureRuntimeCanvas`），
面板却是 1400 宽，必然左右被裁。收到 1200（左右各留 40）：
列宽 670→570（2*570+20 = 1160 = 列表区宽）、列表区 1360→1160、描述 820→790、
反馈行 920→860、页签 838/1014、翻页组 906/1010/1078、商品条内部 380→320 / 520→420。
**高度 540 没动**（占 720 的 75%）。用户若还嫌大，先调 `ShopPanelHeight` 这一个常量。

**交互**：`PixelButton` 新增 `hoverOnlyVisual`（默认 false，只有商店商品条/卡牌条设 true）。
它屏蔽 `selected` / `pointerDown`，外观只跟新增的 `pointerOver`（真实鼠标）走——
不能复用 `pointerInside`，那个会被 `OnSelect` 置 true，点击后仍然亮着。
悬停反馈 = 底图往暖白偏（`hoverWarmth` 默认 0.5）+ 悬停缩放；点击不留持久高亮。

**必须知道的坑**：`ApplyButton` 和 `EnsureRowReadable` 会把底图刷成纯色，
对 `hoverOnlyVisual` 按钮必须跳过，否则 `ForceStockBackground` 钉死的
「带内嵌亮边木牌」会被冲掉。常态色改由 `ForceStockBackground` 经
`SetRestingColor` 告诉 PixelButton，悬停结束才能准确复原（买不起的压暗态也一样）。

**测试**：`MapShopViewLayoutTests` 扩到 7 条，新增
`PanelFitsInsideCanvasReferenceWidth`（面板宽 ≤ 1280）、`StockColumnsFitInsideListArea`、
`StockRowHighlightsOnHoverButNotOnClick`（悬停变色 / 按下选中抬起都不变 / 移开复原）。
实测 7/7 PASS，recompile 0 error，ShopMapScene 进 Play 0 error。

**没做成的事**：UI 截图。Play 模式从主菜单场景启动，用 `MapUiFactory` 临时建的 canvas
拿不到场景主题，截出来是灰块 + 主菜单背景，不能当验收图（已删）。

## 追加：点击不再变绿（同日第三轮，merge `2718482`）

用户反馈「点击之后不要变绿，所有的都不要变绿，只保留鼠标悬停变亮」。

**根因（已实证）**：`Assets/Art/Pixel/UI_New/Common/button_selected.png` **本身就是墨绿色**。
`GameUiStyle.SetSelectedButtonVisual(selected=true)` 会换上它。两条触发路径：
1. 点击让 EventSystem 记住选中态，但 `PixelButton.OnSelect` 不刷新视觉，
   要等 **`OnPointerExit`** 才刷 —— 所以是「点完移开鼠标才变绿」，而且之后一直绿。
   测试必须走完整路径 `enter → down → select → up → exit` 才抓得到。
2. 页签更脏：`StyleTab` 只改 `color` 不改 `sprite`，绿图被暖金 tint 染成暗绿。

**改法**：
- `PixelButton` 加 `restingSprite` / `hoverSprite`：`hoverOnlyVisual` 下按真实鼠标换图
  （`button_normal` 棕 → `button_hover` 暖金），这才是「变亮」；没给图则退回颜色提亮。
- `MapShopView.CreateButton` 统一 `hoverOnlyVisual = true` —— 关闭 / 页签 / 翻页 / 商品 / 卡牌全算，
  点击不再触发任何底图或颜色变化。
- `StyleTab` 显式清 `sprite` 走纯色（当前页暖金 / 非当前深棕），并同步 `SetRestingColor`。
- `ForceStockBackground` 常态底图从 `button_selected`（绿）改为 `button_normal`（棕）。

**主题贴图速查**（`Assets/Resources/StudentGrowth/UI/StudentGrowthPixelTheme.asset`）：
button_normal 棕 / button_hover 暖金 / **button_selected 墨绿** / button_pressed / button_disabled。
以后凡是「按钮自己变色」的问题，先看是不是换到了 button_selected。

**测试**：8/8 PASS（新增 `TabsNeverTurnGreenOnClick`）。旧码对照 7/8，页签那条 FAIL。
recompile 0 error 0 warning，Play 冒烟 0 error。

## 环境坑（这次踩到的，下次别重复）

1. **后台任务结束时 Unity 会被回收**。`ensure_unity.ps1` 跑完即退的调用方式，Unity 会在 30-60s 内
   自行退出（Editor.log 里是正常 shutdown 路径，不是崩溃，很容易误判成"Unity 崩了"）。
   可行做法：后台任务里 `& ensure_unity.ps1` 之后再 `Start-Sleep 900` 把任务吊住。
2. **批处理 `-runTests` 在这台机器不可用**：跑到包注册阶段就被掐，`shop_layout_tests.xml` 从不生成。
   改用 MCP `run_tests`，或临时 Editor 菜单 + 反射跑 NUnit。
3. **MCP `run_tests` 全量会超时**：命令队列上限 60s，报 `Command expired after 60000ms in queue`。
4. **编辑模式 `ScreenCapture.CaptureScreenshot` 抓不到运行时新建的 Overlay Canvas**，
   出图只有场景 HUD、没有商店面板，别拿它当 UI 验收图。
5. 强杀 Unity 后 `Temp/UnityLockfile` 会残留（0 字节），新实例会几十秒内自行退出；
   确认无 Unity 进程后删掉再启动。
