### 3. 商店界面 `MapShopView.cs`（改动最大的文件）

最终布局 **1400×540**：

| 区块 | 内容 |
|---|---|
| 顶栏 | 图标 40 / 标题 30 号 / 金币图标+文本 / 关闭 112×46 |
| 描述 + 页签 | 道具 / 卡牌 两页签 160×46，共用同一块列表区 |
| 列表区 | 1360×344，2 列 × 3 行 = 6 件/页，横条 670×108 |
| 底部 | 反馈行 900 宽 + 翻页组（上页/页码/下页） |

**关键机制**（都是用户实测反馈驱动的修复）：

- 图标加载：`ResolveItemSprite` / `ResolveCardSprite` —— imagePath 读盘 → icon 字段 → GameArtAssetCatalog 约定路径 → 主题兜底，静态缓存 **只缓存成功结果**（null 不缓存，否则某次失败就永久坏）
- 按钮高亮：`PixelButton.highlightOnHoverOnly = true`（商店启用）—— 高亮只跟 `pointerInside`，不看 `selected`。因为鼠标点击会让 EventSystem 记住选中态，点过就永远亮着。**默认 false**，三处现有依赖（BattleUiStyler / MapFunctionMenuView / StageHubSelectionController）不受影响
- 底图钉死：`ForceStockBackground()` 在 Configure*Button 末尾强制 `buttonSelectedSprite` 优先（用户要的带内嵌亮边版）→ `buttonSprite` → 纯色；买不起只整体压暗不换图，保证 6 条外观一致
- 商品可点性：`interactable = CanAfford(...)` 保持，买不起显示灰态（曾试过恒 true，用户实测后回退）
- `RebuildLayout()`：按面板宽度 `!= 1400` 判定旧版本，`DestroyImmediate` 全部子节点 + 清空**全部**字段引用后重建。两个致命坑已修：`SetParent(自己)`、`Destroy` 延迟销毁导致两套 UI 并存
- 翻页：道具/卡牌各自记页码（`stockPage` / `cardPage`），`Refresh` 里 Clamp
