# 显示模式应用与回滚：实施记录

日期：2026-09-05。目标工程：Unity 6000.4.6f1 / StandaloneWindows64。

## 完成内容

- 复用 SettingsService、AudioSettingsController 的常驻生命周期、现有设置 JSON 仓库和设置入口。
- DisplayIntent 为不可变玩家偏好，SettingsSnapshot 保留原窗口属性作为兼容读取入口；新增显示器索引/可选稳定 ID、刷新率分子分母、独占模式。旧 v2 数据缺少新增字段时使用默认值，原有音频和图形设置继续保留。
- RuntimeSettingsState 单独保存实际模式与 LastKnownGoodDisplayMode。匹配、启动降级、恢复不修改玩家偏好。
- 显示器、分辨率、分数刷新率过滤、去重、排序；无边框按桌面解析，窗口限制在工作区内，独占选择最接近模式。恢复按会话恢复点、桌面、安全窗口执行。
- 请求后至少等待两帧，默认最多观察 2 秒、连续匹配 3 帧；刷新率容差 0.6 Hz。显示器迁移完成后才提交分辨率，再等待两帧观察。
- 15 秒实时确认；1.5 秒焦点宽限、失焦禁用确认并暂停、回焦至少 5 秒、后台超过 30 秒恢复；暂停后在恢复应用时回滚。退出不保存候选。
- 危险显示事务独占，TransactionId 校验回调；View 销毁只要求服务回滚，常驻所有者继续驱动协程。现有地图切换入口拒绝事务中切换；强制卸载场景触发恢复。
- 安全图形先独立提交；仅 VSync / 帧率改变不触发确认，显示回滚不撤销已提交的安全设置。
- 确认后分别保存偏好和 DisplayRecovery.json，记录硬件摘要；写盘失败保留 dirty，重试保存不会重切显示模式。跨启动采用当前观察到的安全启动模式作为恢复点，不把磁盘记录当作当前硬件已验证模式。
- ESC 设置面板增加四项显示选项和确认层，F11 走同一事务；危险事务中应用、返回和其他输入被禁用。Canvas 按宽高比适配，避免竖屏、16:10、21:9 裁切整页。

## 使用方式

独立 Player 中按 ESC，在显示区域选择目标、窗口模式、分辨率与刷新率，点击应用；切换验证后选择保留，或等待 15 秒恢复。F11 同样打开设置并走确认流程。窗口/无边框使用桌面刷新率，独占才开放刷新率选择。

编辑器中保留音量/VSync/帧率功能，显示模式控件禁用并说明需独立运行；不会把 Game View 尺寸冒充真实显示模式成功。

SettingsService.ApplyPendingAsync 是组合应用入口；同步 ApplyPending 仅提交安全域，不提交 Pending.DisplayIntent。异步流程由 AudioSettingsController 驱动。重试恢复必须调用异步显示恢复入口，不能用安全域恢复解除显示故障。

恢复记录路径：`Application.persistentDataPath/Settings/DisplayRecovery.json`，与 `StudentGrowth.Settings.v2.json` 分开。

设备验收顺序：

1. Windows Player 从现有游戏入口打开设置；分别切换窗口、无边框、可用的独占模式，确认后重启检查偏好。
2. 改分辨率后不确认，等待 15 秒；检查恢复原模式。仅改 VSync/帧率时不应出现确认层。
3. 切换中 Alt-Tab，检查短暂失焦、暂停倒计时、回焦至少 5 秒；后台超过 30 秒及暂停恢复路径。
4. 在两台显示器间切换；拔掉保存偏好的显示器后重启，检查当前降级而偏好保留；重新连接再启动。
5. 测试 16:10、21:9、竖屏以及 DPI 125%、150%、175%、200%；确认控件、确认层和恢复按钮可见可操作。
6. 确认中关闭设置对象、强制切场景、退出 Player；重启应读取上次确认的意图。
