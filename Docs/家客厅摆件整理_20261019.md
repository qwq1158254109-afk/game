- Console：0 error

## 二、根因：装饰落点公式是错的

`HomeRoomsBuilder.BuildRoom` 里装饰按"精灵左下角"定位：

```csharp
// 旧
go.transform.localPosition = new Vector3(d.pos.x - w * .5f, d.pos.y, 0f);
```

但 `Assets/Art/Pixel/Generated/HomeReference/Props` 下所有 sprite 的 pivot 都是 **(0.5, 0.5)**（中心）。
后果：每件装饰**左移自身宽度的一半**，且 y 被当成中心而不是底边。
实测证据：左右两把椅子规格写 ±4.6，实际包围盒中心在 ±5.54——画面里左右不对称就是这个原因。

```csharp
// 新：用 Sprite.bounds 推，pos 精确落在底边中心
go.transform.localPosition = new Vector3(
    d.pos.x - sp.bounds.center.x,
    d.pos.y - sp.bounds.min.y,
    0f);
```

新约定：**`DecorSpec(x, y)` = 底边中心**，全四间房统一（另外三间重建时才会生效）。

## 三、客厅这版怎么摆的

房间：画幅 30×18，可走区 24×14（内沿 x∈[−12,12]、y∈[−7,7]），相机 ortho 8。

| 组 | 物件 | 落点（底边中心） |
|---|---|---|
| 玄关（南墙） | 门垫 / 鞋柜 / 鞋架 / 小柜 / 衣帽架 / 壁架 | (0,−6.5) / (−3.0,−7) / (−1.75,−7) / (2.6,−7) / (4.0,−7) / (−6.0,−7) |
| 起居（北墙） | 沙发 / 边几 / 落灯 / 地毯 / 茶几 / 两靠垫 | (0,4.8) / (2.5,5.0) / (3.2,5.05) / (0,3.48) / (0,3.15) / (−1.9,2.95) / (1.9,2.75) |
| 边柜 | 矮柜（左）/ 边柜（右）/ 窄柜×2 | (−8.6,5.2) / (8.2,5.3) / (±11.3,1.9) |
| 绿植 | 左上 / 左下 / 右下 | (−11.4,4.9) / (−11.3,−6.6) / (11.3,−6.6) |

**删掉 7 件**：两把办公转椅、客厅书架、2 盆散植物、1 个北墙小柜、1 个东墙边几。

关键间距（已按包围盒核过）：

- 地毯顶边 4.75 ↔ 沙发底边 4.8（整理前隔 3.3）
- 门 x=0 两侧最近物件 −1.15 / +2.11
- 三个房门（东 y=0 / 西 y=0 / 北 x=−6）与四个出生点，1.5 半径内无物件

**为什么删椅子**：`home_ref_chair.png` 把圆毯烘死在图里（128×138），它就是"书房转椅"。放进客厅 = 凭空多两块圆毯，这是原来最违和的东西。

## 六、还没解决的

1. **下半场空**：家具全贴南北墙，y∈[−4,2] 是纯地板。这是 30×18 画幅 + 24×14 可走区的物理结果（此前已选方案 A 接受）。
2. **门洞是黑的**：左右墙 y=0、北墙 x=−6 三处门洞，底板只画了洞没画门，走过去像墙破了。修这个要改 `tools/make_rooms.py` 重烘底板。
3. **缺扶手椅素材**：Props 里没有无毯座椅，客厅只能靠沙发一组撑。
4. **另外三间未动**：卧室/书房/厨房仍是 31×18 + ortho 8.6，且带同样的落点偏移（重建时才套用新公式）。
5. **尺度未统一**：统一到 30×18 需重烘三张底图。

## 八、这轮踩出来的环境坑

见 `AGENTS.md` §20.4，摘要：

- 每次 recompile 都会让 mcp-unity 的 WebSocket 重绑失败（`Port 8096 is already in use`）→ 编译后必须重启 Unity
- 强杀 Unity 会留下僵尸 8096 监听（pid 已消失、netstat 仍 LISTENING）→ 不等它消失就启动，新 Unity 会静默没有 MCP
- Game 视图 1x 会裁切，判断摆件用 `Capture Room Screenshot`
