### 实施补充与兼容边界

- 为使六种卡可从普通地图入口试玩，给 ChallengeData 增加可选 loanDeck。空列表仍使用玩家永久牌组；非空仅用于本场实例生成和视图。不会临时覆盖永久牌组，不需把借用牌归还或写入存档。
- 卡牌仍按 CardType.Study 判断学习类别，不用文字标签隐式决定规则。旧有有符号负推进保留原义；没有状态时原卡数值不变。
- 新效果追加到枚举末尾，未重排旧值；旧 AddTemporaryBuff 等未实现效果继续阻断，没有改变全局 GainEnergy 语义。
- 旧意图复制适配器同时复制新增 durationTurns，防止混合配置丢失显式时长。原 Legacy 挑战仍保留旧默认攻击、抽牌顺序、无手牌上限与超额进度；新的辅助零伤害轮转只用于显式 Unified 策略挑战。
- 六张卡图直接引用先前已导入的六张学习插画，状态图标引用同一 BattleUIConfig。未重新编辑图片或改变原素材的导入设置、PPU、过滤、压缩、Sprite Mode 或 GUID。
- 书桌选项说明面板增加空间，明确原活动收益、两种挑战入口和借用牌组去向。

## 使用方式

1. 从主菜单开始游戏，进入家地图，靠近并面向书桌，按 E。
2. 选择“策略练习 · 1 时间”。“确认”仍执行整理计划，“习题挑战”仍使用当前永久牌组。
3. 点击卡牌或将单目标推进卡拖到挑战面板；悬停卡牌可查看基础效果与本次实际效果，悬停状态行可查看生效区间。
4. 观察敌方轮转并组合专注、推进、格挡、抽牌和能量。终局后返回地图，可按已有流程保存。
5. Windows 版本位于 `E:/unity/ML-project/Builds/P4/StudentGrowth.exe`；运行或复制时保留同目录的 Data、MonoBleedingEdge、UnityPlayer.dll 等依赖。

开发菜单：`Tools → Student Growth → Battle → P4`。正常试玩不需要重新运行资产生成菜单；该菜单会按此报告的原型配置更新 P4 专用资产，手动调数后不要无意重置。
