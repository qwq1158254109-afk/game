# 战斗系统 v03：P0＋P1 与现有美术接入验收

日期：2026-09-06。范围依据用户确认：先完成 P0＋P1，并导入、切片和接入当前可用美术。

## 完成内容

- 保留 ChallengeController、StageController、DeckController 和现有 Resolver；增加会话内唯一 BattleResultConsumer。挑战奖励先执行，阶段奖励随后执行，重复完成、结果重开、继续按钮重入和旧窗口迟到回调不重复发奖或推进；返回去重标记归属于本场记录。
- 结果展示不再调用 CompleteBoss 发奖。最小本场记录包含已有 RuntimeSessionId、battleId、挑战／阶段来源、结果、完成度、回合数及消费状态。
- 意图由执行端生成 LegacyIntentSnapshot；展示与实际行动读取同一个快照。保留当前回合首个匹配项决定伤害、全部匹配项顺序执行附加效果的旧行为。
- 开局被动达到目标后立即结束，不继续初始抽牌或开放输入。非法配置在清空牌堆／扣费之前被阻止。
- 新增效果／目标／关键词支持校验，过期控制器的出牌及结束回合不再改变状态。
- 部分奖励执行发生异常时，标记 Faulted、停止重试、禁用结果继续操作，并阻止该结果保存。没有承诺事务回滚。
- 五张原 PNG 原样导入，切出 70 个 Sprite，接入适用的卡图、图标、进度条、按钮四态、Tooltip 和完成／未完成窗口。

## P1 支持矩阵

|---|---|

| AllEnemies／RandomEnemy／未知目标 | 开战与出牌前报错。 |

| DrawCards | 从牌堆抽牌，保留旧无手牌上限行为。 |
| GainEnergy／LoseEnergy／ReducePressure／AddPressure | 维持长期学生字段语义。 |
| AddTemporaryBuff／AddStatusCardToDrawPile／AddStatusCardToDiscardPile／ExhaustCard 效果／ModifyNextCardEffect | 当前 Resolver 是空实现，校验直接阻止使用；不因图标已导入而认为规则可用。 |
| retain／ethereal／非零 discardCount | 尚未实现，直接阻止。 |

## 使用方式与测试步骤

1. 在 Unity 打开既有 SampleScene 并 Play，使用原阶段活动／Boss 入口；达到阶段条件后开始挑战。当前打开的 ClubRoomMapScene 没有因此新增普通地图战入口。
2. 可直接使用 `Tools > Student Growth > Battle > Verify P1 in Play Mode` 重跑隔离验收。要求当前场景没有未保存修改，且没有其他隔离测试在运行。测试会自动进入／退出 Play，使用真实视图与独立临时存档目录，并输出截图。
3. 使用 `Tools > Student Growth > Battle > Audit P0 P1 content` 输出当前配置报告。
4. `Import supplied v03 artwork` 可重建本批切片与绑定，并保持既有切片 ID。该菜单会恢复本批定义的切片及四张卡图绑定，手工扩展绑定前请先更新导入器定义。
5. 手工复核可重点检查：出牌费用、取消拖拽不扣费、意图与下一行动一致、结果只结算一次、返回阶段后继续活动以及暂停存档。地图出生点、所有场景跳转与发布构建没有因本批自动验收而被声明全面通过。

## 注意事项与下一批边界

本批没有引入 BattleEngine、CardInstance、完整 BattleView 抽离、状态组合、奖励三选一、新地图战闭环、挑战中存档或事务恢复。结果窗口当前展示本场结果、完成度、原因和累计通过数，完整奖励明细展示模型留待后续结果提交改造。

Faulted 状态可阻止本场再次消费和保存，但已经发生的长期效果或部分奖励不会自动回滚。应通过暂停菜单读取原存档／退出；完整恢复、离开过渡、成本和时间事件一致性仍需按 P3 合同实现。恢复旧存档后按其稳定阶段 ID 防止已通关阶段再次发奖，不宣称实现跨崩溃的完整提交事务。
