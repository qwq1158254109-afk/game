普通胜败不会完成阶段；失败保留入场成本。固定奖励可使用活动默认的参与／胜利／失败／阶段分类，也可在单条 RewardData 上覆盖分类。普通挑战完成次数按活动 ID 与胜败写入已有 locationState.actionUseCount。

阶段 Boss 不再收取普通活动成本。失败可重试，包括最终 Boss；失败不占用阶段完成标记。胜利后的清关计数、奖励、下一阶段状态、阶段专属物品清理和下一阶段入场奖励都进入同一冻结计划，返回按钮不再单独发放阶段奖励。普通战用尽阶段时间时，返回过程直接交接 Boss，期间不开放保存。

旧兼容方法仍保留以兼容原有调用和测试；EngineOwned 记录禁止旧 Complete／CompleteStage 路径发奖。正式数值执行使用 Engine，正式结果由同一个消费者提交。P2 的隔离演练仍可从其开发菜单使用。

## 使用方式

1. 从主菜单开始游戏，进入家地图。
2. 靠近书桌并面向书桌，按 E 打开确认界面。
3. 点击“习题挑战 · 1 时间”。“确认”仍对应原来的整理计划。
4. 点击手牌，或把单目标牌拖到右侧目标面板；点击“结束回合”继续。
5. 查看结算后点击“继续 / 返回地图”。返回失败时使用同一按钮重试；已提交的成本与奖励不会重复应用。
6. 阶段时间耗尽后完成战斗交接，或使用地图上的“进入阶段挑战”。Boss 失败后可重新挑战。

普通 Windows 构建位于 `Builds/P3/StudentGrowth.exe`。运行时必须保留同目录的 `StudentGrowth_Data`、`UnityPlayer.dll`、`MonoBleedingEdge` 等依赖，不要仅复制 exe。
