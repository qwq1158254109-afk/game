# 家 · 四房间：薄墙 / 门洞 / 门（2026-10-19 最终版）

前置：`家客厅摆件整理_20261019.md`（第一轮只做客厅摆件）
本篇 = 第二轮（四间统一 + 薄墙 + 门洞改造）与第三轮（补门扇 + 画幅对齐视野）合并记录。

## 一、这轮解决什么

| 反馈 | 做法 | 结果 |
|---|---|---|
| "墙壁占用太大空间" | 墙厚 3.0 → 侧/北 1.5、南 2.0 | 画面里只剩一圈窄墙边 |
| "门框黑洞" | 洞口地板压暗到 45% + 门槛 + 双线门框 | 不再是一块纯黑 |
| "每个房间之间没有留门" | 每个洞口贴一扇门贴图 | 四间房的门在画面里都看得见 |
| "门都不在墙上" | 门改为**画进墙体**（同南墙正门做法）：门高 = 墙厚 - 16，贴住墙内沿 | 门在墙里，不再浮在地板上 |
| （门仍被裁掉） | 画幅从 30×18 收到 **28.5×16.5**，与相机视野 28.44×16 对齐 | 墙和门不再被裁到画面外 |
| "其他房间也照这样" | 四间全部重建，同一套分区规则 | 观感统一 |

## 二、几何参数（四间一致）

```
画幅   28.5 × 16.5（1824 × 1056 px @ PPU 64）
墙厚   侧/北 1.5（96px）  南 2.0（128px）
室内   25.5 × 13.0   →  x ∈ [-12.75, 12.75]，y ∈ [-6.25, 6.75]
相机   orthographicSize = 8（16:9 视野 28.44 × 16）
洞宽   1.5（96px）
```

**为什么画幅要 28.5 而不是 30**：相机视野宽 28.44、高 16。画幅 30×18 时左右各被裁 0.78、上下各裁 1.0，1.5 厚的墙只剩 0.7 可见，靠墙的门直接压在画面外。收到 28.5×16.5 后裁切只有 0.03/0.25，墙和门完整进画面。

## 三、烘焙脚本 `Tools/make_rooms.py`

原脚本只在 `_backup_roomsize_20261019_125422\` 留了旧版（3 单位厚墙），本轮按新参数重写并放回工程 `Tools/`。

关键点：

1. **墙厚**：`W_SIDE = W_TOP = 96`、`W_BOTTOM = 128`，四间统一 1824×1056。
2. **门洞**：先铺地板 → 洞口整块 `ImageEnhance.Brightness(0.45)` 压暗 → 4px 门槛 → 6px 深色外框 + 2px 暖色内线。
3. **门**：`home_ref_exit_door.png`（150x125，带门框那张）画进墙体：
   - **方向跟墙走**：南北墙正着放；东西墙先 `rotate(90)` 再放（竖墙里的门是横的）；
   - **尺寸铺满洞口**：缩放时长边 = 洞口净宽（96px），短边自然落在墙厚内；
   - 门后补 8px 深色门套。

   两个改版教训：
   - 第一版把门从墙内沿朝房间画 → 门浮在地板上；
   - 第二版门进了墙，但没旋转、且用了竖长比例的门贴图（64x136），在 96px 方洞里只占 40px → "方向大小都不对"。

## 三·补：门的最终样式（2026-10-19 第五轮，照主菜单那扇门）

主菜单背景里的门 = `home_ref_exit_door.png`（木质门套 + 上方门楣、四格窗、左右两个铜把手、近似方形 1:1.1）。
房间里统一用**程序化绘制**复刻它的样子（`_make_door()`）：

- 门套：外框 (150,104,64) + 顶部高光条 (196,148,100)
- 门身：(106,54,20)，三条竖板线
- 四格窗：暖白 (242,222,176) + 十字窗棂
- 把手：左右各一，铜色 (210,170,96)
- 尺寸：**门高 = 墙厚 - 10，宽 = 高 / 1.14**（不再是 1:2.1 的窄长条）

**方向**（门底永远朝房间）：

| 墙 | 旋转 |
|---|---|
| 南 / 北墙 | 不转 |
| 西墙 | `rotate(+90)`（窗在左端） |
| 东墙 | `rotate(-90)`（窗在右端） |

**顺带修**：客厅南墙正门之前在改版中丢了（旧的专用绘制段被删、南墙又没开洞），
现在给客厅补上 `bottom` 门洞，和其他门走同一条流程。

**房间对应关系**（进哪个门就在目标房间的对侧出现）：

| 从客厅走 | 进入 | 目标房间里的门 | 落点 |
|---|---|---|---|
| 东门 | 卧室 | 西墙 | (-11.95, 0) |
| 西门 | 书房 | 东墙 | (11.95, 0) |
| 北门 | 厨房 | 南墙 | (0, -4.9) |

## 四、生成器 `HomeRoomsBuilder.cs` 改动

1. **常量**：`RoomW/H = 28.5/16.5`、`Ortho = 8`、`InnerHalfW = 12.75`、`InnerTop = 6.75`、`InnerBottom = -6.25`。
2. **四间 props/decor 按新内区重排**：家具贴墙、底边中心锚点、避开门洞与出生点。
3. **修了移动边界 bug**：旧代码按 `walkSize` 以原点对折算边界，而新内区 y 不对称（南墙 2.0 / 北墙 1.5），会多切掉靠北墙的区域。现改为直接用内沿常量：

```csharp
rpg.movementMin = new Vector2(-InnerHalfW + .9f, InnerBottom + .9f);   // (-11.85, -5.35)
rpg.movementMax = new Vector2( InnerHalfW - .9f, InnerTop - .9f);      // ( 11.85,  5.85)
```

4. **书房去掉 `DeskRoundRug`**：书桌转椅贴图自带圆毯，底下再压一块会出现双毯重影。

## 五、四间布局（2026-10-19 第六轮：按家具逻辑重排）

排布原则（这轮才立起来）：

| # | 规则 |
|---|---|
| A | 侧墙（东西）只放窄件（≤1.4 宽）或绿植；宽件（≥2.4）只上南北墙 |
| B | 地毯必须压在对应家具下面（中心对齐），不做"摆件" |
| C | 落地灯必须贴着一张桌子/椅子（间距 ≤0.4） |
| D | 同款"果篮边柜"只留在客厅/厨房，卧室改矮柜、书房改小柜 |
| E | 同组家具间距 ≤0.4；组间走道 ≥1.2 |

| 房间 | 分组 | 位置 |
|---|---|---|
| 客厅 | 玄关（壁架→鞋柜→鞋架→门垫→小柜→衣帽架）、起居（沙发+边几+灯、茶几压地毯中央）、侧墙窄柜、南角绿植 | 南墙 / 北墙 / 东西墙 |
| 卧室 | 睡眠组（床+两侧床头柜+床头灯）、衣柜、床尾地毯、西门口地垫、南墙小柜+矮柜 | 北墙 / 北墙右 / 床尾 / 西门 / 南墙 |
| 书房 | 工作区（书桌+椅）、书墙（矮柜+高柜并排）、西南阅读角（椅+灯）、南墙小柜、东墙窄柜 | 北墙 / 北墙右 / 西南 / 南墙 |
| 厨房 | 北墙连续操作台（柜→灶→水槽→冰箱，顶边对齐）、中岛、餐区（地毯压桌下+旁灯）、南墙小柜 | 北墙 / 中部 / 东南 |

**这轮修掉的四类硬伤**：

1. 2.48 宽的边柜立在侧墙上（会向房间凸出 2.5 单位）→ 全部只上南北墙
2. 厨房地毯在餐桌南侧、卧室地毯压在衣柜下 → 改成中心对齐
3. 孤立落地灯（书房/厨房各一盏悬空）→ 贴到椅旁/桌旁
4. 同款果篮边柜撒满四间 → 卧室换矮柜、书房换小柜
